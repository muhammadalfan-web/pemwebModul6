1. Jelaskan secara singkat apa itu JavaScript dan kegunaannya! 
JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif dan dinamis. 
JavaScript dapat menjalankan perintah tertentu ketika pengguna melakukan tindakan pada halaman web.
Kegunaan JavaScript antara lain :
a. Menampilkan pesan atau kotak dialog kepada pengguna.
b. Meminta dan mengolah data yang dimasukkan pengguna.
c. Mengubah teks, warna, dan elemen pada halaman web.
d. Menangani tindakan pengguna, seperti klik tombol.
e. Membantu memvalidasi data pada formulir.
Contohnya, fungsi prompt() dapat digunakan untuk meminta nama pengguna,
sedangkan document.getElementById() dapat digunakan untuk mengambil elemen HTML berdasarkan ID-nya.
2. Jelaskan secara singkat apa itu jQuery dan kegunaannya!
jQuery adalah library JavaScript yang menyediakan fungsi-fungsi untuk mempermudah pengolahan elemen HTML dan interaksi pada halaman web.
Dengan jQuery, beberapa perintah yang biasanya ditulis menggunakan JavaScript dapat dibuat lebih singkat.
Kegunaan jQuery antara lain :
a. Memilih elemen HTML berdasarkan ID, class, atau nama elemennya.
b. Menangani kejadian seperti klik tombol.
c. Mengubah tampilan elemen, misalnya warna latar.
d. Menyembunyikan dan menampilkan elemen.
e. Membuat efek sederhana pada halaman web.
Contoh fungsi jQuery yang digunakan pada soal nomor 5 adalah .click(), .css(), .hide(), dan .show().
3. Jelaskan perbedaan JavaScript dan jQuery!
Pengertian : JavaScript Bahasa pemrograman untuk web.
             jQuery Library yang dibuat menggunakan JavaScript.
Penggunaan : JavaScript Dapat digunakan langsung di browser.
             jQuery Menggunakan fungsi-fungsi yang disediakan oleh library jQuery.
Pengolahan Elemen : Menggunakan API JavaSript bawaan browser
                    jQuery Menyediakan metode yang lebih ringkas untuk banyak operasi DOM
Ketergantungan     : JavaScript tidak membutuhkan library jQuery
                     jquery membutuhkan library jQuery agar kode dapat dijalankan
